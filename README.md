# 予約管理ツール — 公開デモ v1.0.0

蛍光管持込・家具家財撤去・ビン缶回収を題材に、利用者の申込みと管理者の受付業務を一つにつないだポートフォリオ作品です。カテゴリーごとの受付方法、日別の予約枠、変更・取消・再受付の履歴まで確認できます。

**[公開デモを開く](https://reservation-tool-next-demo.netlify.app/)** · [利用者画面](https://reservation-tool-next-demo.netlify.app/reserve) · [管理者画面](https://reservation-tool-next-demo.netlify.app/admin)

![カテゴリー別の予約状況と選択日の予約を確認できる管理カレンダー](docs/images/02-admin-calendar.png)

## この作品で取り組んだこと

予約は、申し込んだ時点で日程が確定するものばかりではありません。本作では、蛍光管持込は空き枠があれば即時確定、家具家財撤去とビン缶回収は受付後に電話調整する流れとして設計しました。申込者への案内と管理者の状態操作を、その違いに合わせています。

| 業務上の課題 | 実装した対応 |
|---|---|
| 受付と確定の混同 | 受付・確定・完了・取消の4状態と、カテゴリー別の完了案内 |
| 日ごとの受付量の調整 | カテゴリー別の日別上限、受付停止、管理者の満枠例外受付 |
| 変更後の経緯が分からない | 操作履歴、取消予約と再受付先の相互参照 |
| 複数日にわたる作業の管理 | 関連番号でつなぎ、日ごとに枠と状態を管理 |
| 二重送信や古い画面からの更新 | 再送識別、保存直前の再検証、版・世代の競合検出 |

## まず試す操作

1. 管理者画面で「管理画面を試す」を押し、カレンダーと予約一覧を確認します。初期データは架空の予約9件です。
2. 一覧の `DEMO-009` を開き、取消元 `DEMO-002` とのつながりと操作履歴を確認します。
3. 利用者画面で蛍光管持込を選択し、架空情報と受付可能日を入力します。確認後に申し込むと「確定」になります。
4. 同じブラウザの管理者画面で登録した予約を確認します。家具家財撤去・ビン缶回収では、申込み後の状態は「受付」です。
5. 試用後は管理者画面の「初期状態に戻す」で初期データを復元できます。

日付と初期予約は利用日に合わせて生成されるため、画面の年月日は掲載画像と異なる場合があります。

## 主な機能

- 利用者：カテゴリー選択、空き日の選択、入力検証、確認、受付番号の表示、受付内容の印刷、同じ依頼者での連続申込み
- 管理者：月間カレンダー、検索・絞り込み付き一覧、予約詳細、電話受付、内容変更、確定・完了・取消、再受付、関連作業日の追加
- 受付設定：カテゴリー別上限、日付別受付停止、過去日の未完了予約の案内
- 保存：IndexedDB、同一ブラウザの複数タブへの変更通知、初期状態への復元、データ削除

## デモの範囲

**実在する会社名・氏名・住所・電話番号を入力しないでください。** 管理者画面にパスワードはありません。本番用の認証機能を示すものではありません。

予約・設定・履歴は、同じブラウザ・同じ公開元のIndexedDBに保存します。異なる端末やブラウザとは共有しません。予約入力をGAS・Googleスプレッドシート・本番APIへ送る実装はありません。サイトの表示にはNetlifyへの通信が発生します。

最後にデモ画面を開いてから7日を超えると、次回起動時に初期予約9件へ戻ります。「データを削除して終了」でもデモの予約・設定・履歴を削除できます。

本番認証、共有データベース、バックアップ・復旧、顧客通知、利用者自身によるオンライン変更・取消、決済・料金計算・売上連携は対象外です。実運用時には別途設計が必要です。

## 技術構成

React 19 / TypeScript 6 / Vite 8 / React Router 8 / IndexedDB / BroadcastChannel / Vitest / Testing Library / Oxlint / Netlify

```text
src/
  reserve/          利用者画面、日付選択、変更通知
  admin/            管理者画面
  domain/           入力・日付・受付枠・状態の業務ルール
    storage/        IndexedDB、初期データ、履歴、競合制御
  test/             テスト共通設定
docs/
  portfolio.md      掲載用の紹介文
  images/           公開デモの実画面
  image-guide.md    掲載順、キャプション、代替テキスト
  verification.md   v1.0.0の確認記録
```

保存処理では、予約・履歴・再送識別情報をIndexedDBの同一トランザクションで扱います。ブラウザ間共有やサーバー側の排他制御を実装したものではありません。

## ローカル起動

検証環境：Node.js 24.18.0 / npm 11.16.0 / Windows。Node.js 24系を推奨します。依存関係の固定には `package-lock.json` を使用します。

```sh
git clone https://github.com/skamatakiwriter-rgb/reservation-tool-next.git
cd reservation-tool-next
npm ci
npm run dev
```

完成版を再現する場合は、インストール前に `git checkout v1.0.0` を実行します。
