# 予約管理ツール Ver2 ローカル操作ガイド

更新日：2026年9月28日
対象：`feature/v2-dispatch-management`

## 1. 起動

```text
npm ci
npm run dev
```

表示されたローカルURLを開く。Ver2はまだ公開していないため、既存のNetlify URLではVer1が表示される。

## 2. 画面

| URL | 役割 |
|---|---|
| `/` | デモ入口 |
| `/reserve` | 利用者の予約申込み |
| `/admin` | 予約・配車管理 |
| `/driver` | ドライバー担当確認・作業結果 |

すべて架空データである。実在する会社名、氏名、住所、電話番号を入力しない。本番認証はなく、データは同じブラウザ内だけに保存される。

## 3. 予約・配車管理を確認する

1. `/admin`で「管理画面を試す」を選ぶ。
2. カレンダーの「すべて」表示で、該当日に「受付停止 N」「上限超過 N」が表示され、下部の凡例で意味を確認できることを確認する。
3. カテゴリーを選び、該当日に予約数／上限数と「受付停止」または「上限超過」が表示されることを確認する。
4. 配車・回収状況の集計から、未配車、配車済み、回収中、要再配車、要対応、要再確認を確認する。
5. 「予約一覧」を開き、受付番号で検索する。
6. 予約を選び、依頼内容、社内補足、配車・回収、履歴が別領域になっていることを確認する。

初期データの主な確認例は次のとおりである。日付はデモを初期化した日に応じて変わる。

| 受付番号 | 確認内容 |
|---|---|
| `DEMO-010` | 未配車、社内補足あり |
| `DEMO-011` | 配車済み、ドライバー向け指示あり |
| `DEMO-012` | 回収中 |
| `DEMO-014` | 一部回収済み・要再配車 |
| `DEMO-015` | 回収不可・要対応 |
| `DEMO-016` | 配車後の予約変更・要再確認 |
| `DEMO-017` | 全量回収済み、車両は積み置き中 |

## 4. 配車を登録する

1. `DEMO-010`を開く。
2. 受付中は「予約を確定すると配車を登録できます」の案内を確認し、「予約を確定する」を選ぶ。
3. 操作可能になった「配車を登録する」を選ぶ。
4. 予定日、開始・終了時刻、車両、主担当ドライバー、必要なら指示を入力する。
5. 保存後、予約一覧が「配車済み」になり、操作が「配車を変更する」へ変わることを確認する。

車両の積載情報は判断材料であり、自動的な適合保証ではない。保留中の車両は選択できず、同じ車両または担当者の重複時間帯は保存できない。

## 5. ドライバー画面を確認する

1. `/driver`で架空ドライバーを選ぶ。
2. 「今日」「明日」「今後7日」または「期間を指定」から表示期間を選ぶ。任意期間は最大31日。
3. 日付別の担当案件を選び、回収先、依頼時申告、顧客連絡事項、ドライバー向け指示を確認する。
4. 必要な場合だけ「回収開始を記録」を使う。開始記録なしでも結果登録できる。
5. 終了時に「全量回収」「一部回収」「回収できず」を選ぶ。

同じ日・同じ車両・同じ主担当ドライバーで回収を続ける場合は、作業結果を登録せず現在の状態を維持する。

## 6. 作業結果と車両保留

- 全量回収：予約を完了する。
- 一部回収：今回の配車を終了し、予約を要再配車にする。実際の回収内容と次回対応を入力する。
- 回収できず：予約を要対応にする。理由と次回対応を入力する。
- 回収後に搬入できない：管理者が回収結果とは別に搬入判断待ちを記録する。
- 電話相談で車上保管が決まった：管理者が積み置き中へ変更する。
- 荷下ろし等で積載が解消した：理由を入力して保留解除する。

ドライバー画面には車両保留を表示するが、保留判断の入力操作はない。

## 7. 試用後

- 「初期状態に戻す」：Ver2完全初期データへ戻す。
- 「デモを終了する」：保存データを残して管理者モードだけ終了する。
- 「データを削除して終了」：ブラウザ内の業務データを削除する。

データ削除は元に戻せない。確認用の操作を続ける場合は「初期状態に戻す」を使う。

## 8. Ver1からVer2へ切り替える場合

同じブラウザ・同じ公開URLでVer1を利用していた場合、Ver2の初回表示時にブラウザ内の予約、変更内容、操作履歴を保持したままDB版2へ移行する。

Ver1を開いた別タブが残っていると、ブラウザがDB版更新を止めることがある。その場合はVer1のタブをすべて閉じ、Ver2の画面を再読み込みする。初期状態への復元やデータ削除は行わない。
