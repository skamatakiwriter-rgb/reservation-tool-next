## 3. セキュリティヘッダー

`netlify.toml`へ次の応答ヘッダーを追加した。

- Content Security Policy：同一オリジンのスクリプト、スタイル、画像、通信だけを許可し、埋め込み表示とプラグイン用オブジェクトを禁止する。
- Permissions Policy：カメラ、位置情報、マイク、決済、USBを無効にする。
- Referrer Policy：外部遷移時に送る参照元情報を制限する。
- X-Content-Type-Options：MIMEタイプの推測を禁止する。
- X-Frame-Options：他サイトのフレーム内表示を禁止する。

現在のアプリは外部API、外部フォント、外部画像を利用しないため、この制限と矛盾しない。
