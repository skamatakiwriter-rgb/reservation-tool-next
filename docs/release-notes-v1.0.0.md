# v1.0.0 — 予約管理ツール 公開デモ初版

利用者の申込みから管理者の電話受付、日程調整、変更・取消・再受付までを試せる公開デモ版です。

- 蛍光管持込・家具家財撤去・ビン缶回収の3カテゴリー
- 受付・確定・完了・取消の状態管理、カレンダー・予約一覧
- 日別上限、受付停止、関連作業日、再受付の相互履歴
- IndexedDB保存、二重送信・版競合対策、複数タブ通知
